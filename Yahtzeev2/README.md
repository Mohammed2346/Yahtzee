# Yahtzee Game Instructions

Yahtzee is a game for 2 to 4 players.

## Game Setup
- Your page must allow the user to start by specifying the number of players.
- It should display an appropriate number of player areas based on the number of players.

## Gameplay
1. The first player throws the dice. Your game must randomly set the values displayed for a player.
2. The player may choose dice that they want to throw again. You must include a way to select the dice that will be thrown again.
3. In total, each player gets three chances to roll the dice.
4. A player may choose to score based on a set of scoring rules. A scoring rule can only be used once.

## Dice Images
- Create or import your 6 dice images.
- Add them to the page and give them unique IDs.
- Place a check-box next to each die.

## Rolling Dice
- Add a button that will randomly choose a value for the dice that are checked and then display an appropriate image for each of them.

## Player Area
- Use the change/exit event for a control that allows you to change the number of players.
- When this event occurs, the code for the play area should be duplicated accordingly.
